This website is a notebook for anything I feel like writing down. Most often, I feel like writing down thoughts about building things, or documentation for stuff I'm currently building. Entries grouped by subject matter can be found in the [Index](/tags/) section of the website for quick reference. 

I think my motivation for keeping track of things here is primarily posterity (why? mortality?), though as of late I've been inspired to write by reading my former neighbor, friend, Timothy Monger's beautifully assembled [weekly blog](https://www.timothymonger.com/isthissomething). I've also long admired [Ben Katz's](https://robot-daycare.com/) and [Tim Jacobs'](https://mitxela.com/) (aka mitxela) legendary contributions to the maker-specific blog tradition. 

This website was built with [Hugo](https://gohugo.io/), for which I found [this playlist](https://www.youtube.com/watch?v=qtIqKaDlqXo&list=PLLAZ4kZ9dFpOnyRlyS-liKL5ReHDcj4G3) very useful to learn. Generative AI helped tremendously with the CSS styling.
